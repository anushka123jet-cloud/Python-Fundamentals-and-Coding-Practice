# 🐍 Python Fundamentals and Coding Practice

A hands-on Python practice repository covering **Python fundamentals, string manipulation, built-in functions, and beginner-level coding problems**. This notebook was created for strengthening core Python concepts and building problem-solving skills for Data Science and Machine Learning.

---

## 📖 Overview

This repository contains a collection of Python concepts and coding exercises practiced through a Jupyter Notebook.

The notebook starts with fundamental Python concepts and gradually moves toward problem-solving exercises, particularly focusing on **strings and basic programming logic**.
